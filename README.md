# השלמות

רשימת קניות משותפת להורים. אמא מתכננת את הבישולים, אבא קונה, שניהם רואים את אותו הדבר בזמן אמת.

האפיון המלא: [`SPEC.md`](SPEC.md) · גרסה מעוצבת עם מוקאפים: [`docs/spec.html`](docs/spec.html)

---

## מה זה

אפליקציית ווב שמותקנת למסך הבית של האייפון (PWA) — בלי חנות אפליקציות, בלי חשבון מפתח, בלי תפוגה. עלות אפס: GitHub Pages ‏+ Supabase, שניהם במסגרת החינמית.

| | |
|---|---|
| **אמא** (`planner`) | בוחרת מנות → המערכת ממזגת מרכיבים → שולחת לאבא |
| **אבא** (`shopper`) | רשימה מסודרת לפי הדרך שהוא הולך בסופר, מסמן מה נקנה / חסר / הוחלף |
| **אתה** (`admin`) | הקמה, צירוף מכשירים, תמיכה. רואה את שני המסכים |

## הקמה

### 1. פרויקט Supabase

צור פרויקט חדש ב־[supabase.com](https://supabase.com). ואז, ב־**SQL Editor**, הרץ את הקבצים לפי הסדר:

```
supabase/migrations/0001_schema.sql
supabase/migrations/0002_rls.sql
supabase/migrations/0003_functions.sql
supabase/migrations/0004_seed_catalog.sql
supabase/migrations/0005_storage.sql
```

### 2. כניסה אנונימית

**Authentication → Providers → Anonymous Sign-ins → Enable.**

אין סיסמאות ואין אימיילים באפליקציה הזאת. המכשיר נכנס אנונימית, ומצטרף למשק הבית בעזרת קוד חד־פעמי.

### 3. משתני סביבה

מ־**Project Settings → API** קח את ה־URL ואת ה־`anon` key.

לפיתוח מקומי:

```bash
cp .env.example .env
# מלא את שני הערכים
npm install
npm run dev
```

ל־GitHub Actions — **Settings → Secrets and variables → Actions → Variables**:

| שם | ערך |
|---|---|
| `VITE_SUPABASE_URL` | `https://xxxx.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | `eyJhbGciOi…` |

שניהם ציבוריים מעצם התכנון — ה־`anon key` נשלח לדפדפן וכל טבלה מאחוריו מוגנת ב־RLS. לכן הם **משתנים** (variables) ולא סודות.

### 4. GitHub Pages

**Settings → Pages → Source: GitHub Actions.**

הריפו צריך להיות ציבורי — Pages בריפו פרטי דורש מנוי בתשלום. הקוד גלוי, הנתונים לא.

דחיפה ל־`main` תפרוס אוטומטית ל־`https://<user>.github.io/hashlamot/`.

### 5. שני ה־Workflows

| | |
|---|---|
| `deploy.yml` | בונה ופורס בכל דחיפה ל־main |
| `keepalive.yml` | פינג יומי ל־Supabase |

**ה־keepalive הוא לא נחמד־שיהיה.** פרויקט Supabase חינמי נכנס להשהיה אחרי שבוע ללא פעילות, והשימוש כאן שבועי — בדיוק על הגבול. חופשה או חג היו הורגים את האפליקציה בדיוק ברגע שההורים מנסים להשתמש בה. דקות Actions בריפו ציבורי הן ללא הגבלה, כך שזה עולה כלום.

## ההפעלה הראשונה

1. **פתח את האתר במכשיר שלך** → "אני מקים את זה" → שם הבית ושמך.
   הקטלוג (272 מוצרים ישראליים עם מחלקה, אייקון ויחידה) נזרע אוטומטית.
2. **הגדרות → פתיחת חלון צירוף** → קוד בן 8 תווים, תקף 10 דקות.
3. **בטלפון של אמא**: פתח את האתר → "יש לי קוד" → הקוד → "מכינה רשימות".
4. **בטלפון של אבא**: אותו דבר, עם קוד חדש → "הולך לסופר".
5. **בכל טלפון**: Safari → שיתוף → **הוספה למסך הבית**.

השלב האחרון הוא לא קוסמטי: התראות פוש ב־iOS עובדות **רק** אחרי הוספה למסך הבית. שווה לעשות את זה פיזית מולם.

הקוד חד־פעמי ונשרף מיד אחרי שימוש, והצירוף נשאר סגור עד שתפתח אותו שוב.

## הרשימה הראשונה — לעשות איתה, לא בשבילה

הסיכון הגדול ביותר במוצר הוא לא טכני: שאמא תפתח מסך ריק ותחזור לדף ולעט.

שב איתה. אתה מקליד את המנה הראשונה, היא את השנייה, והיא מסיימת את השלישית לבד. מכאן זה מצטבר לבד — כל שבוע היא מזינה רק את המנות החדשות של אותו שבוע, ואחרי חודש הרפרטואר בפנים.

### שלוש נקודות שכדאי להכיר

**האופליין הוא רכיב, לא הגדרה.** ל־Supabase אין מטמון מקומי כמו ל־Firestore, ובסופר אין קליטה. כל סימון של אבא מוחל מקומית מיד ונכנס לתור ב־IndexedDB. הכתיבה עוברת דרך `apply_item_update` שמתעלמת מעדכון ישן מזה שכבר במסד — כך תור שמתנקז באיחור לא דורס כלום, ושליחה חוזרת בטוחה.

**המיזוג יושב ב־Postgres.** `build_list()` אוסף מרכיבים מכל המנות הנבחרות, מחבר כמויות בתוך משפחת יחידות (ק״ג עם גרם, לא עם "יחידות"), וממיין לפי `department_order` של משק הבית.

**סדר המחלקות נלמד.** לכל פריט שנקנה יש חותמת זמן, אז `suggested_department_order()` יודעת באיזה סדר אבא באמת עבר. אחרי שלוש קניות מוצעת לו התאמה — לעולם לא מוחלת בשקט.

## פיתוח

```bash
npm install
npm run dev          # שרת פיתוח
npm run build        # בנייה
npm run seed:sql     # יצירה מחדש של 0004 מתוך src/data/seed-products.js
node scripts/generate-icons.mjs
```

## מה עוד לא בפנים

התראות פוש (Edge Function + VAPID) — הסכימה כוללת את `push_subscriptions`, הפונקציה עצמה עוד לא נכתבה. עד אז, כפתור "שליחה גם בוואטסאפ" הוא ערוץ ההודעה, והוא ממילא רשת הביטחון המתוכננת.
